# AI Resume Analyzer and Job Recommendation System

An NLP-based Streamlit application that reads a PDF or DOCX resume, finds technical skills, calculates a match score for 7 job roles, recommends the top 3 roles, lists missing skills and gives a weekly learning roadmap.

- Project code and datasets: see the `ai_resume_analyzer` folder
- Colab notebook: `Major Project 1.ipynb`

## Run locally
pip install -r ai_resume_analyzer/requirements.txt
streamlit run ai_resume_analyzer/app.py
